# Portafolio — Samuel Echavarría

Sitio personal estático desarrollado con HTML, CSS y JavaScript, preparado para GitHub Pages.

## Publicación

1. En GitHub abre **Settings → Pages**.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Selecciona la rama **main** y la carpeta **/(root)** y guarda.
4. Espera a que finalice la publicación.

URL esperada: https://28samu.github.io/

## Archivos

- `index.html`: estructura y contenido del portafolio.
- `styles.css`: estilos adaptables a móviles y escritorio.
- `script.js`: menú móvil y año del pie de página.

Los gráficos de proyectos incluidos son representaciones CSS ilustrativas, no capturas reales de las aplicaciones.
